# 电商订单履约系统 需求摘录

## 1 业务背景
面向中小电商卖家的订单履约中台：统一接收多平台订单，自动完成库存校验与扣减、履约调度、物流单回传，并提供对账报表。

## 2 功能需求
- FR-01 订单接收：支持 API 推送与 Excel 批量导入两种下单通道
- FR-02 库存校验：下单即预占库存，不足时进入待补货队列
- FR-03 履约调度：按仓库优先级与物流时效自动分仓
- FR-04 物流回传：发货后回传物流单号至来源平台
- FR-05 对账报表：按日/周生成订单-回款对账表
- FR-06 异常处理：地址异常/超卖/取消单自动拦截并告警

## 3 非功能需求
- NFR-01 峰值 200 单/分钟
- NFR-02 库存扣减强一致（不允许超卖）
- NFR-03 全部页面支持中文
