- 状态机五态：`new → confirmed → fixing → pending_regression → closed`。

## F. 评审修订裁决（波次 0，2026-09-20）

### R-01 错误码两级制：DomainError 与门禁 issue code 分册注册

**问题（评审 P0）**：A3 虽指定 LLD-3 §14 为错误码唯一注册表，但 LLD-1/LLD-2/LLD-5 实际使用约 80+ 表外码，且同义不同码成组（`COMMAND_UNKNOWN`/`UNKNOWN_COMMAND`/`COMMAND_UNSUPPORTED`、`GATE_BLOCKED`/`GATE_DENIED`、`MANUAL_REQUIRED`/`POLICY_MANUAL_REQUIRED` 等）。根因：「门禁 issue code」（423 响应 `details.issues[]` 缺口代码）与「DomainError」（`error.code` 领域错误码）两级码边界从未定义。

**裁决**：

1. **两级制边界**（权威定义在 LLD-3 DSG-C14-1）：
   - **一级 = DomainError**：命令/Provider 失败与 `ApiError.error.code` 的顶级错误码；一次失败响应恰好一个顶级码，映射唯一 HTTP 状态；注册表 = **LLD-3 §14（DSG-C14-2）**。
   - **二级 = 门禁/缺口子码（issue code）**：不单独作为 `error.code` 返回、不映射 HTTP 状态；仅出现在 `GateResult.issues[].code`、423 `details.issues[].code`、检查/审计报告 `issues[].code`、上传 `details.violations[].code`、autopilot `blocker.code`；注册表 = **LLD-3 §15（DSG-C15-1，新增）**。
   - 两级闭集互不重叠，一个码值只在一级注册；门禁阻断顶级码恒为 `GATE_BLOCKED`（或更具体一级码如 `STALE_EVIDENCE`），缺口明细用二级码。
2. **注册表规模**：§14 活跃 DomainError **91 码**（a~j 十组，补 HTTP 状态与使用方列）；§15 活跃 issue code **77 码**（a~l 十二组：设计原型门禁/自测门禁/转测试门禁/任务开始门禁/RTM 健康度/删除守卫/原型检查/来源审计/UI 评分/ZIP 违规/autopilot 阻断/失效传播通用）。
3. **同义码归并（24 组，46 个旧码废止保留于 LLD-3 DSG-C14-3，不删除）**：
   - `UNKNOWN_COMMAND`、`COMMAND_UNSUPPORTED` → `COMMAND_UNKNOWN`
   - `GATE_DENIED`、`TRANSFER_GATE_BLOCKED`、`BUILD_PRECONDITION_FAILED`、`SELFTEST_PRECONDITION_FAILED`、`DELETE_GUARD_BLOCKED`、`RTM_HEALTH_UNMET` → `GATE_BLOCKED`（缺口细节改用 §15 子码）
   - `MANUAL_REQUIRED`、`MODE_SWITCH_DENIED` → `POLICY_MANUAL_REQUIRED`
   - `OPTIMISTIC_LOCK_CONFLICT`、`PUBLISH_CONFLICT` → `VERSION_CONFLICT`
   - `COMMAND_ID_CONFLICT` → `IDEMPOTENCY_CONFLICT`
   - `SNAPSHOT_TAMPERED` → `PREPARED_TAMPERED`
   - `BULK_BASELINE_CONFLICT`、`UPSTREAM_STALE`、`SOURCE_STALE`、`CATALOG_STALE`、`SUBJECT_STALE` → `STALE_EVIDENCE`
   - `CALLBACK_IDENTITY_INVALID` → `OPERATION_STALE`
   - `SETTING_INVALID`、`RESULT_ENUM_INVALID` → `VALIDATION_FAILED`
   - `AUTH_FAILED` → 拆分为 `UNAUTHENTICATED`（401）/`FORBIDDEN`（403）
   - `STATE_INVALID`、`TASK_STATE_INVALID`、`PARSE_STATE_INVALID`、`ZIP_STATE_INVALID`、`DEFECT_STATE_INVALID`、`EXECUTION_STATE_INVALID`、`STREAM_STATE_INVALID` → `INVALID_STATE`
   - `EXECUTION_NOT_FOUND` → `NOT_FOUND`
   - `FILE_TYPE_UNSUPPORTED`、`UPLOAD_QUOTA_EXCEEDED` → `UPLOAD_REJECTED`
   - `REFERENCE_BASELINE_STALE` → `REFERENCE_STALE`
   - `PATCH_STALE`、`PENDING_TARGET_MISMATCH` → `PATCH_BASE_STALE`
   - `CONTEXT_DENIED` → `REFERENCE_NOT_FINAL`
   - `NO_MODEL_AVAILABLE` → `MODEL_UNAVAILABLE`
   - `DELEGATE_TARGET_INVALID`、`DELEGATE_TARGET_UNAVAILABLE` → `DELEGATION_TARGET_UNAVAILABLE`
