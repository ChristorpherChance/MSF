## 唯一权威与入口

| 对象 | 唯一权威 | 写入入口 | 禁止的推断 |
| --- | --- | --- | --- |
| 客户身份 | session.domain / role | 显式模拟登录、退出与会话到期 | 不从页面、hash、预览角色反推身份 |
| 内容事实 | content.status / workflowView / allowedActions / lastTransition | 按冻结映射检查的内容命令 | 不从当前页面或角色产生下一业务状态 |
| 客户路由 | 解析后的 page / lang / 参数 | 初始 URL、hashchange、真实导航点击统一进入 customerRoute | URL 不携带“可信预览”属性 |
| 设计预览 | 独立 previewSelection | 既有显式 prototypeNavigate / 验证来源为父窗口的设计预览消息 | 不进入客户路由解析，不写 session 或 content |
| 可见页面 | 客户授权决策或明确的预览投影 | 先决策、后一次性显示 | 不先显示受保护工作台再等待点击拒绝 |

删除 `show(page, state, externalBoolean)` 作为公共分派方式。使用分别命名的 `renderCustomerDecision()` 与 `renderDesignPreview()`，二者可复用无副作用的 DOM 呈现函数，入口不互相调用。普通 CMS 路由未经认证时只显示登录页；Citizen 显示 denied；已登录 CMS 角色按角色和内容事实确定可见目标或无待办空态。

## 内容转移与投影

使用一个显式转移表返回完整的新事实；验证通过后一次性赋值。失败保持所有内容事实与审计不变。页面不再通过“非 published/archived 都是 pending-publish”兜底。

| 动作 | 输入事实 | 输出事实 | 前台投影 |
| --- | --- | --- | --- |
| Editor 提审 | draft 或 returned，允许 submit | status=review，workflowView=submitted | 不增加公开内容 |
| Reviewer 通过 | review/submitted，允许 approve | review/pending-publish | 保持未公开 |
| Reviewer 退回 | review/submitted，允许 return | draft/returned | 保持未公开 |
| Publisher 发布 | review/pending-publish，允许 publish | published/published | HOME、SECTION、CONTENT 同步公开 |
| Publisher 下线 | published/published，允许 unpublish | review/pending-publish，lastTransition.action=unpublish | 三处同步不可见；可重新发布既有审核版本 |
| Publisher 归档 | 当前事实允许 archive | archived/archived | 三处撤下，详情显示 410 |

`unpublished` 仅作为前台可见性投影/提示语，不成为 workflowView 或数据库状态。所有输出必须属于 `statusDisplayMapping.canonicalStorageStates` 与 `workflowViewStates` 的既有允许集合；未知组合直接阻断，不自动增补目录。若希望下线后重新审核，那是单独的业务选择，不混入这次实现。

### 冻结的事实 schema

沿用既有 API 契约，`allowedActions` 只保存服务动作，不保存按钮命令：`edit`、`submit-review`、`approve`、`return`、`publish`、`unpublish`、`archive`。`lastTransition` 为对象 `{action, actorRole, at, reason?}`；action 使用同一服务动作枚举，actorRole 为真实操作者，at 为事件时间。初始无转移时为 null；不得保存 `publisher:unpublish` 这类拼接字符串。公开 DOM 的说明文字可以格式化，但输入事实和报告仍保留结构化对象。

| 合法 status / workflowView | allowedActions（服务动作） |
| --- | --- |
| draft / draft | edit、submit-review |
| draft / returned | edit、submit-review |
| review / submitted | approve、return |
| review / pending-publish | publish、archive |
| published / published | unpublish、archive |
| archived / archived | 空数组 |

该固定示例只接受上表组合；仅分别属于两个枚举集合还不够。角色约束在命令层再次核对，`allowedActions` 不授予错误角色权限。`review-queue` 是 Reviewer 页面的呈现状态，不成为 workflowView。

| 现有 UI 命令 | 服务动作 |
| --- | --- |
| switch-lang-pair-language / add-content-block / save-draft-with-revision | edit |
| submit-content-review | submit-review |
| approve-for-publish | approve |
| return-to-draft | return |
| publish-with-preflight | publish |
| unpublish-content | unpublish |
| archive-content | archive |
| view-read-only-content / view-audit-records | 只读查询，核可见性，不写入 allowedActions |

唯一状态内核维护为可独立运行的纯函数，输入当前完整事实、服务动作和真实 actor；模板与独立构建静态嵌入它或各自按同一冻结规范实现。纯函数单测直接核对完整 pair、精确 actions、结构化 transition 和失败零写，不新增产品公共调试接口，不通过 DOM 提示文本反推 API 事实。

## 失败、恢复和写入顺序

1. 路由解析只产生规范化客户请求；非法参数回到公众首页。
2. 根据当前 session、content 判定授权与可见页面；不能复用上一次预览的角色或状态。
3. 内容命令先核角色、当前事实与 allowedActions，再用唯一转移表得到完整新事实。
4. 校验冻结映射与派生投影；失败零写，成功一次性提交后更新可见 DOM。
5. 普通路由与预览交替、退出后 hashchange、session 到期均重新走同一客户决策，不保存可提升权限的旧页面状态。

无跨刷新持久化；刷新仅恢复示例种子及按授权解析 URL。保留现有单业务 DOM，不增加第二份“检查专用页面”。
