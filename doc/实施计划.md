- 工件属于客户项目「喀麦隆门户网站」；MSF 平台页面不是客户 UI。
- 旧 V1.1～V1.8 目录不可变；工作在 `.worktrees/v19`；不碰用户 agent-lab 目录移动。
- 单 HTML 唯一实现者，不改 DevStore 公共契约、不接真实服务、不增加跨刷新持久化。
