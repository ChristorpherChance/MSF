# V1.11 资料目录优化方案

状态：限定功能及六套专项关联回归通过；非全系统验收。

最新用户确认覆盖：ZIP上传仅保留原包，行内手动解压为同名文件夹，替代下文早期自动解压约定。解析稿删除仅自身、保留原件；有定稿/加工/引用依赖时阻止。解析区新增独立选择与人工确认的批量文件解析定稿，不改变内容和需求定稿。详见修改说明追加章节。

## 1. 基线与不变项
🔴 **直接复制 V1.9，不迁移 V1.10 模块。** 文件解析／内容解析、正文预览编辑、人工定稿、公共对话、下游五阶段流程保持原有结构。基线旧目录校验记录见 baseline-hashes.json。继承的 v1.9 文档仅是历史背景，不是新版验收结论。

## 2. 上传与树
🔴 **ZIP 上传后自动解压，普通文件仍可上传。** 支持 STORE／DEFLATE；校验路径、本地头、中央目录、CRC 与大小，拒绝加密、链接、ZIP64、多卷、危险路径和重复条目。上限：输入30MB，100项，单文件10MB，总展开25MB。包内全部验证后一次提交，失败不留半包。重名自动编号，嵌套 ZIP 不递归展开。
目录展开状态、文件选择保存在 S；折叠不影响已选；文件夹支持全选、取消、半选；批量操作针对全部已选而非当前可见节点。

## 3. 两个目录，同一文件身份
🔴 **原始文件/包名/内部路径与解析文件/包名/内部路径.md 一一对应。** 原件解析后仍保留。同 basename 不同扩展名使用保留扩展名／编号解决输出碰撞。沿用 S.files 稳定 ID 与状态；目录不是需求引用工件。
Markdown UTF-8 真实读取，原始二进制与 Markdown 可下载；复杂文件转换仍是明确模拟，图片等不支持时明确失败。文件夹和 Blob 仅在页面内存，刷新会丢失，非磁盘归档。
新上传带项目归属，导入和解析回调校验项目与任务身份。全应用多项目隔离是既有欠账，本轮不宣称解决。删除沿用 V1.9 双向删除与引用同步，不新增回收站。

## 4. 冻结范围
不改 V1.10，不新建工作台，不加派生成果体系、不改通用AI、不接真实Office/PDF/OCR、多模态与知识库、不做永久存储、不重构五阶段项目数据、不提交推送打tag。

## 5. 挂钩与验收
资料主逻辑沿用 msf-prototype.html 的 matFileHtml、batchParse、retryParse、dlFilePopover；新增 ZIP 维护源及静态嵌入。保留客户模板、状态内核、构建和验收工作台维护源不变。
先失败测试再实现；覆盖 ZIP 正常／恶意／损坏边界、折叠勾选、路径和原件保真、下载、异步竞态；真浏览器与既有回归。测试前说明，结束页面标注结果，旧目录哈希复核。结果写原型修改说明，不继承旧版证据为新版通过。
