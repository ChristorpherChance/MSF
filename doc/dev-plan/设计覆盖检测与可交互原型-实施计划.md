# 设计覆盖检测与可交互原型 — 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development，逐任务实现+两阶段评审。

**Goal:** 三合一——①PRD↔设计 覆盖补强+过度设计检测（规则筛查+AI 复核落 DR）；②设计文档↔原型单页
结构化对应+双向检查；③综合可交互原型（页内穿流+流程视图+flow 校验）。

**Architecture:** 规格=`doc/dev-plan/设计覆盖检测与可交互原型-设计.md`（评审 Approved，含
C1/C2/I1~I6/N1~N3 修法——实施前必读全文）。唯一 schema 变更=迁移 0031（dsg_catalog_refs CHECK 含 'ui'）；
AI 复核 purpose='review' 命令 design.review.selfcheck；滞后判定=时间基（页 updated_at < ui 册版本 submitted_at）。

**Tech Stack:** NestJS + pg 直驱 + React 18；vitest（集成测试 scp 到 101 跑，命令见 Task 7）。

**全局纪律（每个任务都适用）：** 错误码闭集零新增；审计失败零写；豁免/DR 结论/定稿全部人工
（AI 只提不判）；嵌套 LLM 绝不在命令事务内；跨域只 SQL 直读不写；console 只 warn/error；
中文注释/文案；样式全 var()；toast kind 只 default|success|warn；直接 main 逐任务 commit
（message 末尾 `Co-Authored-By: Claude Code <noreply@anthropic.com>`）；tsc 在 apps/server 或
apps/web 内分别跑；`pnpm lint` 必须仓根跑；集成测试改 101 后 `git checkout` + rm 恢复受控树。
