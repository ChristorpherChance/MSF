# MSF 开发任务分解

> 版本：V1.0 · 2026-09-21 ｜ 配套：`开发计划.md`（里程碑定义与门禁）
> 粒度规则：M0/M1 已展开到任务级；M2 及以后在临近时展开（避免过度计划）。
> 任务格式：`T<里程碑>-<序号>` ｜ 状态：⬜ 未开始 / 🚧 进行中 / ✅ 完成。
> 追溯纪律：每个任务标注承接的 REQ/DSG 条目；任务勾选即开发期 RTM 执行层落地；完成定义=代码+测试+lint/typecheck 绿+覆盖率达到该模块门槛。
