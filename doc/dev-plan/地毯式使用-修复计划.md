**日期**：2026-09-27　**依据**：《地毯式使用-问题与疑问.md》39 条登记
**纪律**：13 册冻结基线不动；错误码闭集（先注册后使用）；命令封闭枚举；跨域只经 SQL 直读+platform 纯函数；审计失败零写；人工确认点不可自动化；tsc 在 app 目录内跑；lint 仓根跑；check-codes/check:deps 必过。

## 根因已定位（两条 🔴）

- **U-027 抽屉白屏**：server `tasks.service.ts detail()` 返回字段名 `ci`，前端类型与渲染用 `ciReports` → 证据存在后 `t.ciReports.length` 读 undefined 崩溃。修法：server 返回键改 `ciReports`（前端类型即契约）。
- **U-026 autopilot 空转**：双缺陷叠加——① prepare 路径 `projectedIds` 用 dev_tasks 原始插入序（plan-r2 首任务 T-022 批次 8），违反 dev.task.start 的批次门禁 → 每 tick 必抛 GATE_BLOCKED；② tick 循环 `.catch(() => false)` 静默吞错（15ms 空转、零 blocker、零日志）。修法：① projectedIds 按 (batch_no, code) 排序；② tick 捕获 DomainError 落 blocker（GATE_BLOCKED 等可持续阻断码）+ console 日志，不再静默空转。
