## 一、已验证模式（需求阶段全链实机验证通过）

### P1 阶段化预设（stage-guides）
`ai/stage-guides.ts`：按 dock 所在阶段（ai_sessions.ctx）向 buildPrompt 注入【阶段职责与方法】块。
总纲=**诊断 → 给方案 → 落到可确认提案/可照做步骤**，不停留在泛泛建议。每阶段数百字控预算。

### P2 agentic 接力循环
工具围栏块流末执行后，**结果自动回喂模型**、同一条消息内继续生成（`StreamPipeline.runContinuation`，
封顶 3 轮，usage 累加，stop/暂停对当前轮生效）。修复「AI 只读不答/只说拿到结果后我会」。
接力失败不静默：`console.error` 留痕 + 消息内补「⚠️ 续答生成失败…请重发」可见提示并终止接力。

### P3 对话提案通道（propose_edits）
旁路外部工具（嵌套 LLM 绝不在命令事务内跑）：守卫四人话（未生成/已定稿先解锁/有待确认补丁/枚举校验）、
增量 patch + 整篇 rewrite 双通道、mock 确定性产出（离线可测）、竞态三码翻人话不落码、
用量按 generation 用途落账、route 随结果供工具卡「前往审阅 →」。
**提案必经人工确认**——人工定稿/放行不可自动化的口径不破。

### P4 补丁处置 UX
行级 LCS diff 逐块 md 真渲染（−红/+绿/同灰）；处置四态（接受/改后接受 newText/拒绝/拒绝并回喂 AI）；
常驻吸附批量横幅；提案成功 window 事件自刷新+切页签+toast；工具卡分档「已提交 N 条建议 + 前往审阅 →」。

### P5 上游变更联动（upstream-stale）
纯只读派生（零 schema）：下游有已提交版本且上游当前版本更新 → stale。三落点：
UI 徽标「⚠ 上游已变·待复核」、提交即通知+事件（同事务落库+pushExisting 补推 SSE）、
agent【联动提醒】块（带版本号主动建议跟随修订）。链路 CRD→PRD→设计八册不跨级。

### P6 界面编号 ⇄ 模型可见文本的双向对齐
UI 派生编号（第五章/5.1）是渲染层产物，模型不可见——`buildNumberGuide` 向增量 prompt 注入
「UI 编号 ⇢ 原始标题」对照表+禁编号前缀约束；`findSection` 统一命中口径
（锚点码任意位置→精确→编号剥离精确→≥4 字符后缀）；doc.read 返回带界面编号标题+anchor 定向读。

### P7 doc.read 读口径
草稿优先（与 UI 同口径）、finalized/modified/versionNo 如实返回、sections 章节清单（未命中自助重试）、
anchor 四形态（编号 token/大章序/锚点码/标题）、offset 分页续读、12000 字截断给 nextOffset。

### P8 声明点同步纪律（W4-003）
工具/能力任何改动，**模型侧全部声明点同批更新**：能力边界、工具清单、尾句、阶段指南、注册表 description。
测试钉死（sessions 套件断言声明文本）。

### P9 失败可观测
AI 失败三层穿透：classifyAiError 闭集归类 + sanitizeAiError 脱敏 + error 帧带 message + 失败行落库；
接力轮失败见 P2；网关分钟级瞬断（503 auth_unavailable）属已知外部风险，UI 给「请重发」出口。

### P10 长耗时操作可见性三件套（2026-10-06 增补，「点了没用」根修）
任何真模型驱动的按钮（60s+）：①调用期常驻进度提示（非仅置灰）；②完成后回环导航
（广播领域事件自动切到结果落点页，如 msf:req-proposed / msf:dsg-proposed）；③结果在落点页立即可见
（补丁高亮+常驻横幅）。toast 即逝不算提示。

### P11 围栏协议容错（2026-10-06 增补，「让 AI 改编号没反应」根修）
模型输出截断/漏闭合是常态形态：```msf-tool 围栏解析必须容错**回合末尾未闭合但体部合法**的块
（剥离+执行+回喂照常），**半截 JSON 绝不执行**（防半参数调用）；剥离用 span 减法不留残渣。
另：**批量重编号/批量改标题类诉求必须走 mode:rewrite**——patch 通道按标题/锚点匹配既有节，
标识符本身就是匹配键，一变全误判 add、接受即新旧节重复（实机三现：RTM 补齐首跑、CRD 重编号首提）。

## 二、配套机制（非对话层但同闭环）

- **RTM 覆盖闭环**：「⟳ 重建映射并检查覆盖」（rtm.rebuild+实时健康度一键入口）→ 缺口横幅
  「✨ AI 补齐缺口」（coverageFixFromGaps 按缺口清单向 CRD/PRD 定向提案，承接锚点=缺口码、编号顺延；
  **PRD 侧优先整章重写语义对应但锚点陈旧的既有节，确无对应才新增**——CRD 重编号场景防整批复制）
  → 人工确认补丁 → 提交版本 → 再检查转绿。幂等（无缺口 results 空）。

## 四、纪律红线（各阶段应用时不得突破）

- 提案必经人工确认；定稿/放行永远人工；审计失败零写；错误码闭集不加码（人话不落码）；
- 命令先注册 command-bus 闭集；旁路工具仅当前两件（req/design propose_edits）——新增须先补 WRITE_TOOLS/TOOLS 双闸校验（终审 Minor-1 登记项）；
- 声明点同步（P8）；mock 通道确定性产出（离线可测）是任何新 AI 通道的硬要求。
