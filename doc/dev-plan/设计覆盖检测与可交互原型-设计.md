# 设计覆盖检测·原型对应·综合可交互原型 — 设计

> 2026-10-15 立项。缘起（用户原话）：「概要设计文档与详细设计文档如何检测能完全覆盖需求 PRD，
> 并不过度设计；如何保障将最新的设计文档与 UI 原型的单页面都能对应上，并最终出综合的可交互 UI 原型」。
>
> 勘查钉死的现状缺口：①RTM 只查 from 侧正向三层（R→CR/CR→REQ/REQ→DSG），**无反向「过度设计」检出**；
> coverage-fix 只补 CRD/PRD 两域不覆盖 L0C_BELOW；②原型页表只记 catalog_version+指纹，**无「依据哪些
> 册/章节」结构化记录**，页级 prompt 不注入 UI 册正文；③汇总原型跨页交互止于跳页/切态，
> **flow 条目不渲染不校验**；DR 评审是三条 mock 种子+人工结论（review.service.ts 注释自标
> 「M6 真接后由自检评审产出」）。
>
> 用户拍板三决策：①过度设计=**规则筛查+AI 复核**；②对应=**结构化对应+双向检查**；
> ③原型交互=**全套（页内穿流+流程视图+flow 校验）**。

## 1. PRD↔设计 覆盖与过度设计检测

**覆盖侧补强**：「AI 补齐缺口定向提案」（coverage-fix）从 CRD/PRD 两域扩展到 **L0C_BELOW**
（REQ→DSG 缺口）——定向提案落到对应设计册（propose 补承接章节，锚点回引 REQ-nnn 满足 L0c 派生）。

**过度设计侧（规则+AI 两段）**：
- 规则筛查：rtm-health 增反向维度——设计册锚点节无 REQ 回引（标题与正文均无 REQ-nnn）入
  「疑似过度设计」候选清单；**册级粗链不算承接**（粗链只解锁门禁不证内容有据）；
  人工豁免位（deferred 同款：理由必填、自指行留痕、不计待办）；
- AI 复核：候选清单逐节调 AI 产复核意见（「看似无需求依据：…/实为合理技术决策：…」），
  分析调用非文档编辑（purpose 路由复用现有模型解析口径）；
- 结果落点：复核意见落成**真实 DR 评审项**（落地 review.service.ts「由自检评审产出」的既有
  设计意图），人工三值结论（pass/fail/na）挂既有定稿门禁。**豁免/结论全部人工，AI 只提不判**。

## 2. 设计文档↔原型单页 结构化对应 + 双向检查

- `dsg_catalog_refs` 增 `ref_kind='ui'`：plan 时页面条目同步写「页→ui 册章节」refs
  （section_id/anchor/rule_text 快照+ref_fingerprint，复用 PRD refs 快照机制）；
- 页级 prompt 注入 UI 册正文（页面相关章节优先，节选上限同 PRD 24000 口径）；
- 双向一致性检查（进 check 与状态查询）：册有页无（UI 册页面章节无目录页）/页有册无
  （目录页无 UI 册章节承接，可豁免）/内容滞后（ui 册章节 ref_fingerprint 漂移→受影响页面清单，
  「该页依据的 ui 册 §x.y 已变更」——滞后页进 PROTOTYPE_DIRTY 同款门禁，重生成页面指纹刷新自动解脏）；
- 可追溯呈现：原型页签显示「本页依据：ui 册 §x.y（✓一致/⚠已变更）+ PRD REQ-nnn」。

## 3. 综合可交互原型（穿流+流程视图+flow 校验）

- **页内点击穿流**：页面契约增 `data-nav` 属性（页级 prompt 约定：跳转类按钮/链接挂
  `data-nav="#P-002"` 可带状态 `#P-002/s2`；纯展示按钮不挂）；validatePageHtml 增校验
  （目标必须是目录内页码）；汇总 NAV_SCRIPT 增事件委托——点击 [data-nav] 切目标页+hash 同步；
- **流程视图**：flow 条目（F-001 步骤链）进汇总渲染——汇总增「流程」视图：每 flow 一条步骤条
  （步骤=页面/状态引用），点击步骤跳对应页面状态；flow 步骤引用在 plan 时声明
  （seed 从 UI 册流程章节/PRD 推导，人工可改）；
- **flow 校验进 check**：flow 引用的页面/状态必须存在+data-nav 目标必须存在，
  悬空均出 issue 拦定稿（PROTOTYPE_DIRTY 同口径）；
- **冻结兼容**：manifest 增 flow 快照+data-nav 目标清单；旧版汇总原型（无 data-nav）永久可预览，
  新校验只对新生成生效（版本向前兼容）。

## 纪律与测试口径

- 错误码闭集零新增；审计失败零写；豁免/DR 结论/定稿全部人工（AI 只提不判——铁纪律）；
- 跨域只 SQL 直读不写；console 只 warn/error；样式全 var()；toast kind 只 default|success|warn；
- 嵌套 LLM 绝不在命令事务内（AI 复核/页级生成全在事务外）；
- 单元：反向筛查纯函数（无回引检出/豁免剔除/粗链不算承接）；data-nav 校验；双向一致性检出；
- 集成（101 跑）：L0C coverage-fix 定向提案落设计册；AI 复核→DR 项落库→人工结论挂门禁；
  plan 写 ui refs→指纹漂移→受影响页面清单→重生成解脏；flow 校验拦截；穿流契约 validatePageHtml；
